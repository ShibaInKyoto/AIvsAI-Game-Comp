# Gridbreaker

Download `Gridbreaker-windows-x64.zip`, extract it anywhere and run `Gridbreaker.exe`.
No installation or extra runtimes are required (Windows 10/11, any GPU with OpenGL 3.3).
The executable is not code-signed: if SmartScreen appears, choose **More info → Run anyway**.

## What's inside

- A neon twin-stick roguelite: five sectors, five guardian bosses, a living warp grid
  over a per-sector parallax backdrop, HDR bloom, shockwave distortion and a
  hyperspace jump between sectors.
- Six ships, 39 upgrades, seven weapon modules and seven legendary evolutions.
- Campaign (with an epilogue and credits for destroying the Core), Endless (compounding
  loops and corruption), Boss Rush and a Daily run with a daily rule-twisting mutator,
  on three difficulties.
- Sector events, sector protocols, elites and data caches, combo scoring.
- Hangar unlocks and permanent firmware, sixteen challenges, records with run history,
  and a codex with a how-to-play guide.
- Contextual tips for first-time players; automatic render scale that adapts to slower GPUs.
- Keyboard and mouse or gamepad (with rumble), procedural music and sound.

Press **F11** or **Alt+Enter** to toggle fullscreen. Progress is saved in `%APPDATA%\Gridbreaker`.
